# Hey there, I'm Guillermo 👋

AI Engineer 🇪🇸 with a CS engineering degree and a Master's in Artificial Intelligence from Maastricht University 🇳🇱. I work at [Dealroom.co](https://dealroom.co), where I've spent 5+ years building the ML and data systems behind the product.

Most of my time goes into building reliable LLM systems for production: agents, tools, structured & grounded outputs, and evals.

## 🔭 What I work on

- 🤖 **Agents & tool use**: LLM agents that automate data curation, with internal services exposed as MCP tools
- 🔎 **Retrieval**: hybrid search (dense + lexical), chunking strategies, reranking, embeddings and vector indexes
- 📊 **Evals & observability**: benchmarks, regression suites and human-in-the-loop review for LLM/NLP systems
- ☁️ **Serving on GCP**: containerized services, CI/CD, streaming ingestion and low-latency data APIs
- 🧠 **Classic NLP**: fine-tuned RoBERTa multi-label classifiers and NER models for unstructured text
